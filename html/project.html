Project Details

JS Element 1: DOM Manipulation - MCU Fact Geranartor

On the home page, a “MCU Fun Fact” box will display a random Marvel fact each time the user clicks a button. An array of fun facts will be stored in a variable. When the button is clicked, a JavaScript event listener will pick a random index from the array using Math.random() and update the inner text of a DOM element with the selected fact. This demonstrates array usage, event listeners, and DOM manipulation all in one concept. You can view the element implemented here: Home page


JS Element 2: Toggle - MCU Phases

Each MCU phase section will be displayed as a collapsible accordion. When a user clicks on a phase header, a JavaScript event listener will check using an if/else statement whether the content panel is currently visible or hidden and toggle its display accordingly. This keeps the page clean and easy to navigate while demonstrating event handling and conditional statements. You can view the element implemented here: MCU Phases Page


JS Element 3: Forum - MCU Fan Forum

a. A fan forum submission form will allow visitors to enter their name, email, favorite MCU character, and a comment or message. JavaScript will validate all fields when the user clicks submit, checking for empty inputs, a properly formatted email address, and a minimum character count on the message field. Error messages will be dynamically displayed using DOM manipulation based on if/else logic, and a success confirmation message will appear once all fields pass validation. You can view the element implemented here: Fan Forum
